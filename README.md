# entry-u-motasimfuad-notes-from-a-passive-aggressive-fridge-83c00ad7 — Notes From a Passive-Aggressive Fridge

One funny passive-aggressive note a smart fridge leaves for its owner, a single line of 129 characters:

> You opened me 14 times today, stared, and took nothing. The leftovers have filed a formal complaint, and frankly, I co-signed it.

Why this line: it speaks in the fridge's own smug voice — it counted the door opens, it logged the staring, it knows the owner's habits better than the owner does. The concrete detail is the leftovers, the pettiest possible grievance, and the sting lands in the last clause: the fridge is not just reporting the complaint, it co-signed it. The appliance has taken sides against its owner, which is exactly the dry, domestic grudge the brief asks for. No generic nagging, no explained joke.

## Run it

```sh
python3 main.py
```

`main.py` (Python 3 standard library only, no network, no randomness) writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (falling back to `/output`) and asserts the competition's gate itself: 1–200 characters, one line, not only whitespace. The line is a fixed string, so two runs produce identical bytes.
